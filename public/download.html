⚙ راه جایگزین: ساخت خروجی روی کامپیوتر خودتان (۵ دقیقه — قطعی)
اگر همه مسیرهای بالا قرمز شدند، این محیط پیش‌نمایش به فایل‌های خروجی دسترسی نمی‌دهد. در این صورت:
  1. برنامه Node.js LTS را از nodejs.org دانلود و نصب کنید (فقط Next بزنید).
  2. سورس پروژه را از همین محیط بگیرید (اگر گزینه Export/Download ZIP در منوی پروژه هست) یا از گیت‌هاب.
  3. در پوشه پروژه، یک ترمینال (CMD) باز کنید و این دو دستور را بزنید:
    npm install و سپس npm run build
  4. پوشه dist ساخته می‌شود — محتوای آن همان خروجی نهایی است؛ آپلودش کنید.
